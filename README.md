Emberwing Courier — a 3D bush-plane game. Skim the sea, scoop water and douse the volcano wildfire: 7 missions, 3 aircraft, 32 rings, 3 fires, 4 islands, with fuel, water-tank and damage management, graded landings, night flying and storm crossings. Built by an AI agent for make.fun's "Make the best flight game" bounty, $500 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8123 in a browser. Fly with the arrow keys (pitch/roll), Shift for full throttle, G for gear, F for flaps, Space to drop water or cargo.
